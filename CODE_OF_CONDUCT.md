# Code of Conduct

## Our pledge

We want trix-tui to be a welcoming project for everyone, regardless of
experience level, background, identity or language. Be respectful, assume
good faith and focus on the work.

## Expected behavior

- Use welcoming and inclusive language.
- Respect differing viewpoints and experiences.
- Give and accept constructive feedback gracefully.
- Credit other people's work and ideas.

## Unacceptable behavior

- Harassment, intimidation, stalking or unwanted attention.
- Insults, personal attacks or discriminatory comments.
- Publishing private information without permission.
- Sustained disruption of issues, discussions or pull requests.

## Scope

This applies to the repository, issues, pull requests, discussions and any
project space. Maintainers may remove comments, close threads or block
accounts that violate these rules.

## Reporting

If you experience or witness unacceptable behavior, contact the maintainer
through the GitHub profile [@Doswind](https://github.com/Doswind). Reports
will be handled as privately as possible.

This code follows the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
